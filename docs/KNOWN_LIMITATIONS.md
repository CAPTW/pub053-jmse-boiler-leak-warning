# Known Limitations and Verification Boundaries (`v1.0.2-pub053-r2`)

This document states the exact boundaries of what can and cannot be verified in a standalone clone of `CAPTW/pub053-jmse-boiler-leak-warning`.

1. **Primary Binary `.npz` Archives Are Not Bundled**
   - The 48 `.npz` files (`24` in `data/observations/`, `24` in `data/traces/` from `PUB053_Manuscript_Package_R2.zip`), per-episode `data/original_configs/<episode>_config_applied.json`, and the full study execution package `observable_baseline_study_20260915T215200Z_be142b32.zip` are not included in this public repository and were verified absent across all mounted drives (`C:\`, `G:\`, `O:\`) on the release workstation.
   - Without `--archived-tables-only` (or `--archived-assets-only` for `make_figures_r2.py`), default execution of `code/verify_features.py`, `code/reproduce_analysis.py`, and `code/make_figures_r2.py` **fails with exit code `1`** and `"all_passed": false`.

2. **Raw Observation Reconstruction & Full Raw Replay Proven via Synthetic 24-Episode Test Fixture Only**
   - `code/_common.py::reconstruct_features_from_observations` implements Supplement S3 mathematically (horizontal-cylinder volume $V(h)$, 1,000-knot geometric $\rho_l(p)$ spline with `[0.5, 30.0]` bar detector clipping, 600 s trapezoidal mass-balance residual $r_M$, `ddof=0` OLS/EWMA scale fits on `D1_normal`–`D4_normal` $t \ge 1200\,\text{s}$, and signed `flow_z`, `command_z`, `combined_score = max(flow_z, command_z)`), and `code/reproduce_analysis.py` + `code/make_figures_r2.py::render_figures_from_raw_npz` implement full raw threshold calibration, primary `meta/safety_state` (`label/safety_state`) / `truth/state_feasible` event extraction, 50-row Table 3/4/5/7 cross-checking, and manuscript-matched Figures 1–7 rendering.
   - Because the real 48 `.npz` files are absent, these paths are executed in CI/unit testing (`code/test_analysis.py`, `7/7` tests including `test_raw_feature_reconstruction_and_negative_mutation` and `test_raw_reproduce_crosscheck_and_figures`) on isolated `TemporaryDirectory` 24-episode synthetic `.npz` datasets (`144/144` array matches, negative mutation check perturbing `D1_normal.npz`, full 50-row cross-check with `"kind"` provenance diffs & `"actual"` 12-sig-fig display formatting, and raw Figures 1–7 generation), not on the unbundled study `.npz` trajectories.

3. **Archived-Mode Boundary for `episode_results.csv`, `cutoff_leads_by_block.csv`, and `tables_3_4_5_7_crosscheck.csv`**
   - Under `--archived-tables-only`, `code/reproduce_analysis.py` recomputes delays, strict leads, Table 6 aggregations, cutoff lead differences (`strict_lead_s = functional_start_s - alarm_s`), `delay_window_check.csv`, and internal JSON consistency checks.
   - However, upstream primary alarm timestamps (`all_alarm_times_s`), cutoff `functional_start_s`, `process_trip_s`, `domain_exit_s`, `progression_duration_s`, and Table 4 regression coefficients are read from `results/` and `data/`, not freshly re-extracted from `.npz` traces. `results/tables_3_4_5_7_crosscheck.csv` is explicitly treated as a preserved reference artifact (`preserved_or_copied_artifacts`), never copied as a newly executed check.

4. **Figure Regeneration Boundary (`--archived-assets-only` vs. `full_raw_npz_replay`)**
   - Under `--archived-assets-only`, only `fig4_method_summary_delay_lead.png` is freshly rendered via Matplotlib from CSV; Figures 1–2 are composited/padded from preserved `figures/raw_source_assets/`, Figures 3, 5, 6, and 7 copy preserved R2 panels (`copied_preserved_reference_assets`), and `figure_generation_manifest.json` explicitly reports `all_files_valid: true` alongside `figure_spec_verified.all_specs_verified: false`.
   - Under `full_raw_npz_replay` (with `.npz` files present), `render_figures_from_raw_npz` renders all seven manuscript-matched panels (including Fig 2 panel (b) showing both conditioned observed drum level and dashed plant-truth drum level, Fig 5 unshifted traces with `[0, 0.999]` normalized score/threshold notation, Fig 6 horizontal milestone timelines with `Horizon censoring` `>` markers, and Fig 7 categorical `E1`–`E8` normal `max_exceedance_span_s` vs `600 s`) with `figure_spec_verified.all_specs_verified: true`.

5. **Optional `iapws` Package & Upstream Snapshot Differences**
   - `iapws` (`GPL-3.0`) is intentionally excluded from the MIT-licensed repository requirements. When `iapws` is absent, `code/_common.py` uses IAPWS-IF97 Region 4 $T_{\text{sat}}(p)$ and IAPWS-95 Eq. (2.6) $\rho_l(T_{\text{sat}})$, while `simulator_source/` falls back to its built-in 9-point approximation. With user-installed `iapws==1.5.5`, the 7 core physics/props/protocol modules pass `88/88` tests and the full `simulator_source/tests/` suite returns `151 passed, 2 skipped, 1 deselected, 2 failed`, where the 2 failures (`test_governance_policy_enforces_classification_and_retention` and `test_workspace_compatibility_paths_exist`) explicitly target excluded upstream non-core files (`scripts/check_dataset_governance.py`, `blueprint.md`, `cli/`, `dataset/`, etc.).
   - `simulator_source/` reflects clean local base commit `4fea4646723f04db41583cb682bac8b62c44bc05` rather than the pilot/study-patched `source_copy/` (`observable_baseline_study_20260915T215200Z_be142b32.zip`); see `docs/SOURCE_PROVENANCE.md`.
