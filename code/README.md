# R2 Analysis & Figure Reproduction Scripts (`code/`)

These scripts provide a clean, standalone CLI execution path compatible with the R2 workflow and independent of any private `.docx`/`.pdf` submission files:

- `_common.py` — Shared NumPy detector/EWLS equations (signed `r_m` residuals preserving signs for `z_f` and `z_d`), Supplement S3 raw `.npz` feature/EWMA/threshold reconstruction (`reconstruct_features_from_observations`, `calibrate_thresholds_from_traces`, `extract_raw_trip_and_domain_exit`, `detect_functional_event`), `iapws.IAPWS97` vs. fallback diagnostics (`get_density_backend_info`, noting `iapws==1.5.5` is required for exact raw `.npz` replay because the IAPWS-95 fallback deviates by `0.00079`–`0.20 kg/m^3`), keyed CSV comparison (`compare_csv_files(..., key_cols=..., provenance_cols=..., display_rounded_cols=...)`), JSON helpers, and primary `.npz` availability detection (`full_raw_npz_replay` vs. `missing_primary_raw_npz`).
- `test_analysis.py` — `8/8` unit and integrity tests (stdlib `unittest`) covering sequential persistence confirmation (`score > theta` for `elapsed >= 600` s, `1800` s cooldown), signed `+`/`-` EWLS `r_m` residual formulas, IAPWS-97 (`iapws==1.5.5`) vs. fallback divergence + `missing_iapws_error` CLI guard, empirical quantile upper-tail condition vs. counterexample, Table 6 rounding (`51.3 min`, `115.5 min`), canonical keyed CSV alignment (`cutoff_leads_by_block.csv`), synthetic 24-episode Supplement S3 raw `.npz` reconstruction + 144-array verification + negative mutation failure test (`D1_normal.npz` perturbation), and end-to-end synthetic raw-`.npz` replay (`reproduce_analysis.py` 50-row `tables_3_4_5_7_crosscheck.csv` with `provenance_cols=("kind",)`, `display_rounded_cols=("actual",)`, and Table 7 `None`/`null` list matching + negative check, plus `make_figures_r2.py::render_figures_from_raw_npz` generating Figures 1–7 with `[1200, min(t_end, T_confirm + 300)]` s window and `Observed level`-only Fig 2 panel (b)).
- `verify_features.py` — Default CLI execution requires both all 48 primary `.npz` files (`missing_raw_npz_error`, exit `1` when absent) and `iapws==1.5.5` (`missing_iapws_error`, exit `1` if missing during raw replay unless `--allow-approx-density`); when supplied, reconstructs raw observation features and verifies all 144 trace arrays, `fit_params.json`, `normal_persistence.csv`, and `component_crossing_timing.csv`. With explicit `--archived-tables-only --out results_reproduced`, verifies Table 4 EWLS parameters, Table 5 threshold candidates (`0.990..1.000`), `normal_persistence.csv` (`48/48`), `component_crossing_timing.csv` (`8/8`), and quantile dominance into `results_reproduced/` without overwriting `results/`, reporting 5 explicit provenance buckets (`recomputed_from_raw_inputs` empty in archived mode) and active `density_backend`.
- `reproduce_analysis.py` — Default CLI execution requires both all 48 primary `.npz` files (`missing_raw_npz_error`, exit `1` when absent) and `iapws==1.5.5` (`missing_iapws_error`, exit `1` if missing during raw replay unless `--allow-approx-density`); when supplied, extracts primary `meta/safety_state` (`label/safety_state`) trips and `truth/state_feasible` domain exits (tracking `event_timing_provenance` and failing `all_passed` if `raw_event_fallback_used`), calibrates empirical thresholds, recomputes `96/96` episode-method rows, `32/32` delay-window checks, and the `50`-row `tables_3_4_5_7_crosscheck.csv` (matching `"kind"` provenance diffs, `"actual"` 12-sig-fig display-rounded floats, and Table 7 `None`/`null` list elements without false mismatches). With explicit `--archived-tables-only --out results_reproduced`, verifies the archived outputs and writes `archived_tables_3_4_5_7_internal_checks.json` (`50/50`) without copying `results/tables_3_4_5_7_crosscheck.csv` as newly executed output.
- `make_figures_r2.py` — Default CLI execution requires all 48 primary `.npz` files and exits with code `1` (`all_files_valid: false`, `all_passed: false`) when absent; when supplied, `render_figures_from_raw_npz` renders all seven figures (Figures 1–7) matching the manuscript panel definitions and `[1200, min(t_end, T_confirm + 300)]` s (`1,200`–`11,194 s`) window on Figs 2, 3, and 5 (with Fig 2 panel (b) plotting `Observed level` only, using `truth/drum_level` strictly for dwell-band computation) from raw `.npz` arrays and `episode_results.csv`, recording `figure_spec_verified` alongside `all_files_valid`. With explicit `--archived-assets-only` (or alias `--archived-tables-only`) `--results results_reproduced --out figures_reproduced`, freshly plots Figure 4 from `results_reproduced/episode_results.csv`, deterministically recomposes Figures 1 and 2 from `figures/raw_source_assets/`, stages preserved R2 panels for Figures 3, 5, 6, and 7, and sets `figure_spec_verified.all_specs_verified: false` (raw `.npz` trace plots not regenerated in archived mode).
