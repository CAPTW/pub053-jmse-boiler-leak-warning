# R2 Analysis & Figure Reproduction Scripts (`code/`)

These scripts provide a clean, standalone CLI execution path compatible with the R2 workflow and independent of any private `.docx`/`.pdf` submission files:

- `_common.py` — Shared NumPy detector/EWLS equations (signed `r_m` residuals preserving signs for `z_f` and `z_d`), Supplement S3 raw `.npz` feature/EWMA reconstruction (`reconstruct_features_from_observations`), keyed CSV comparison (`compare_csv_files(..., key_cols=...)`), JSON helpers, and primary `.npz` availability detection (`full_raw_npz_replay` vs. `missing_primary_raw_npz`).
- `test_analysis.py` — `6/6` unit and integrity tests covering sequential persistence confirmation (`score > theta` for `elapsed >= 600` s, `1800` s cooldown), signed `+`/`-` EWLS `r_m` residual formulas, empirical quantile upper-tail condition vs. counterexample, Table 6 rounding (`51.3 min`, `115.5 min`), synthetic 24-episode Supplement S3 raw `.npz` reconstruction + 144-array verification + negative mutation failure test (`D1_normal.npz` perturbation), and canonical keyed CSV alignment (`cutoff_leads_by_block.csv`).
- `verify_features.py` — Default CLI execution requires all 48 primary `.npz` files and exits with code `1` (`missing_raw_npz_error`, `all_passed: false`) when absent; when `.npz` files are supplied, reconstructs raw observation features and verifies all 144 trace arrays, `fit_params.json`, `normal_persistence.csv`, and `component_crossing_timing.csv`. With explicit `--archived-tables-only --out results_reproduced`, verifies Table 4 EWLS parameters, Table 5 threshold candidates (`0.99..1.000`), `normal_persistence.csv` (`48/48`), `component_crossing_timing.csv` (`8/8`), and quantile dominance into `results_reproduced/` without overwriting `results/`, reporting 5 explicit provenance buckets (`recomputed_from_raw_inputs` empty in archived mode).
- `reproduce_analysis.py` — Default CLI execution requires all 48 primary `.npz` files and exits with code `1` (`all_passed: false`) when absent. With explicit `--archived-tables-only --out results_reproduced`, reproduces the 24-episode x 4-detector evaluation (`96` rows), Table 6 summary (`summary.csv`), multi-cutoff sensitivity (`0.70/0.75/0.80 m` -> `5/7/8` observed endpoints, canonically sorted by `(episode, level_cutoff_m, method)`), delay-window equivalence (`32/32`), compares CSVs using explicit row keys, and records Table 3/4/5/7 archived internal checks in `archived_tables_3_4_5_7_internal_checks.json` (`50/50`) without copying `results/tables_3_4_5_7_crosscheck.csv` as newly executed output.
- `make_figures_r2.py` — Default CLI execution requires all 48 primary `.npz` files and exits with code `1` (`all_files_valid: false`, `all_passed: false`) when absent; when supplied, re-renders raw trace curves directly from `.npz` files. With explicit `--archived-assets-only` (or alias `--archived-tables-only`) `--results results_reproduced --out figures_reproduced`, freshly plots Figure 4 from `results_reproduced/episode_results.csv`, deterministically recomposes Figures 1 and 2 from `figures/raw_source_assets/`, stages preserved R2 panels for Figures 3, 5, 6, and 7, and writes `figure_generation_manifest.json` with explicit asset-provenance buckets.
